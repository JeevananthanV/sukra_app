# Sukra App — Setup Guide

Welcome to the **Sukra App Astrological Guidance Application** setup guide. Built with React and Vite.

- **GitHub Repository**: [https://github.com/JeevananthanV/sukra_app](https://github.com/JeevananthanV/sukra_app)
- **Author**: Jeevananthan V

---

## 📋 System Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Git**: v2.30.0 or higher

---

## 📥 1. Clone the Repository

```bash
git clone https://github.com/JeevananthanV/sukra_app.git
cd sukra_app
```

---

## 📦 2. Install Dependencies & Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## 🏗️ 3. Production Build & Linting

```bash
# Run Oxlint linter
npx oxlint

# Build production bundle
npm run build
```
Output files will be generated in `dist/`.
