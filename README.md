## ✨ Features

- **Astrological Consultations**: Planetary charts, planetary periods (Dasha/Bhukti), and astrological forecasts.
- **Sukra Planetary Insights**: Specific guidance on relationships, wealth, art, and prosperity.
- **Ultra-Fast Performance**: Built with Vite and linted using Oxlint.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/JeevananthanV/sukra_app.git
cd sukra_app
```

### Installation & Run

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
